# Amir Math & Science Academy Website

A modern and responsive multi-page academy website built for Amir Math & Science Academy.  
The website provides information about courses, teachers, academy services, and contact details with a clean and professional UI.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and attractive UI design
- Multi-page website structure
- Smooth animations using Framer Motion
- Hero sections with call-to-action buttons
- Courses and services sections
- Teachers showcase
- Contact page with admission form
- Google Maps integration
- Office hours section
- Fully optimized layout and spacing

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- JavaScript
- Vercel Deployment
